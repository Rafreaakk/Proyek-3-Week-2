# Mini Project Modul 2: Portofolio Interaktif Jasa IT Freelance

Proyek ini merupakan Mini Project Modul 2: Vanilla JavaScript dan Interaktivitas Web. Dibangun menggunakan murni HTML, CSS, dan Vanilla JavaScript tanpa framework tambahan, proyek ini mendemonstrasikan manipulasi DOM, penanganan event, filter dinamis, validasi form, dan perubahan antarmuka (seperti tema gelap/terang).

##  Cara Menjalankan HTML Menggunakan Local Server

Untuk memastikan seluruh skrip JavaScript berfungsi dengan sempurna dan menghindari pemblokiran keamanan dari *browser* terkait pembacaan file lokal, proyek ini sebaiknya dijalankan menggunakan **Local Server**.

Berikut adalah cara paling mudah untuk menjalankannya:

###  Menggunakan Ekstensi "Live Server" di VS Code 
1. Buka aplikasi **Visual Studio Code**.
2. Buka folder proyek ini (Pilih menu `File` > `Open Folder...`).
3. Buka tab **Extensions** di sidebar kiri (atau tekan `Ctrl+Shift+X`).
4. Cari ekstensi bernama **Live Server** (oleh Ritwick Dey) dan klik **Install**.
5. Setelah terinstal, buka file `index.html` di editor.
6. Klik kanan di sembarang tempat pada kode HTML tersebut, lalu pilih **"Open with Live Server"**. 
7. Browser utama Anda akan otomatis terbuka dan menampilkan web ini di alamat lokal.


## 📁 Struktur Folder
* `index.html` - Kerangka tata letak dan struktur web dasar.
* `css`/`style.css` - Desain, tata letak responsif, dan *styling* mode gelap.
* `js`/`app.js` - Logika interaktivitas DOM, filter array, dan validasi form.
* `README.md` - Panduan instalasi dan penggunaan proyek.
